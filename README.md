# 🚀 Git-Practice

A repository created to practice **Git** and **GitHub** concepts, commands, and workflows.

## 📌 About

This repository is dedicated to learning and experimenting with Git version control and GitHub collaboration features. It serves as a personal practice space to understand how Git works in real-world development.

## 🎯 Topics Covered

- Git Installation & Configuration
- Repository Initialization
- Git Commands
  - `git init`
  - `git clone`
  - `git status`
  - `git add`
  - `git commit`
  - `git push`
  - `git pull`
  - `git fetch`
  - `git merge`
  - `git branch`
  - `git checkout`
  - `git switch`
  - `git restore`
  - `git stash`
- Branching & Merging
- Merge Conflicts
- Remote Repositories
- GitHub Workflow
- Pull Requests
- Collaboration Basics
- SSH Authentication
- Best Practices

## 📂 Purpose

The goal of this repository is to:

- Learn Git from basics to advanced concepts.
- Practice Git commands regularly.
- Understand GitHub collaboration workflow.
- Improve version control skills for software development and hackathons.

## 🛠️ Tools Used

- Git
- GitHub
- Visual Studio Code
- Git Bash / Terminal
